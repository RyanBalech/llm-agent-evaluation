# Results

This directory is reserved for reproducible benchmark artifacts.

## Rules

- Do not manually edit generated metric values.
- Every headline number must identify the git commit, benchmark version/task IDs, model or
  retriever configuration, and context budget.
- Failed instances remain in the artifact and count toward run accounting.
- Development runs and held-out evaluation runs must be clearly labelled.
- Reference patches are scoring labels only and are never model-visible.
